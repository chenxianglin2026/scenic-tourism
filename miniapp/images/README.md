# TabBar 图标占位文件

本目录中的图标文件为占位文件，上线前请替换为正式的图标资源。

## 需要替换的文件
- `icon-home.png`        - 首页图标（未选中）81x81
- `icon-home-active.png`  - 首页图标（选中）81x81
- `icon-ticket.png`       - 票务图标（未选中）81x81
- `icon-ticket-active.png`- 票务图标（选中）81x81
- `icon-hotel.png`        - 客房图标（未选中）81x81
- `icon-hotel-active.png` - 客房图标（选中）81x81
- `icon-mine.png`         - 我的图标（未选中）81x81
- `icon-mine-active.png`  - 我的图标（选中）81x81

## 图标规范
- 尺寸：81x81 像素（建议使用 162x162 @2x）
- 格式：PNG（不支持 SVG）
- 大小：每个图标不超过 40KB
- 选中态建议使用品牌金色 #c8a052
