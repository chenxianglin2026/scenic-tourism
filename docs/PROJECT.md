---

## 一、项目目标

打造一套面向中小景区的**智慧管理 SaaS 系统**，覆盖"售票 - 入园 - 游客服务 - 数据运营"全链路。

### 1.1 核心目标

| 目标 | 量化指标 |
|------|---------|
| 线上售票 | 覆盖景区 80% 票型，支持微信小程序购买 |
| 快速入园 | 扫码/身份证核销 < 2秒 |
| 游客服务 | 电子导览、实时客流、智能推荐 |
| 数据运营 | 实时大盘 + 营收报表 + 客流预测 |
| 部署成本 | 单景区 VPS < ¥100/月 |

### 1.2 阶段性目标

- **MVP (v1.0)**: 单个景区完整售票+入园闭环，2个月内交付
- **v2.0**: 多景区 SaaS 平台，微信小程序模板化
- **v3.0**: AI 客流预测 + 动态定价 + 智能客服

## 二、项目范围

### 2.1 包含范围 (Scope In)

| 模块 | 说明 |
|------|------|
| 管理后台 (Web) | 票型管理、订单管理、入园核销、财务报表、员工管理 |
| 微信小程序 (游客端) | 购票、订单、电子票、景区导览、个人中心 |
| 后端 API | FastAPI + PostgreSQL，用户认证、支付对接、核销逻辑 |
| 微信支付集成 | JSAPI 支付、退款、对账 |
| 入园核销 | 扫码核销 (小程序扫码 + 闸机接口预留) |

### 2.2 不包含范围 (Scope Out - MVP)

- 智能闸机硬件对接 (仅预留接口)
- 多语言国际化
- AI 客流预测
- 第三方 OTA 分销 (携程/美团)
- App 端 (iOS/Android)

## 六、技术架构概览

### 6.1 整体架构

```
游客端                          管理端
  │                               │
  │ 微信小程序                     │ Web Admin
  │ (原生 WXML/WXSS/JS)           │ (HTML/CSS/JS 单页)
  │                               │
  └───────────┬───────────────────┘
              │ HTTPS
              ▼
     ┌────────────────┐
     │  Nginx (反向代理) │
     │  :443 → API     │
     │  :443 → Admin   │
     └───────┬────────┘
             │
             ▼
     ┌────────────────────┐
     │   FastAPI (后端)     │
     │   Python 3.11+       │
     │   ┌──────────────┐  │
     │   │ 认证/鉴权      │  │
     │   │ 票型管理       │  │
     │   │ 订单管理       │  │
     │   │ 支付/核销      │  │
     │   │ 统计/报表      │  │
     │   └──────┬───────┘  │
     └──────────┼──────────┘
                │
        ┌───────┴───────┐
        │               │
   ┌────┴────┐   ┌──────┴──────┐
   │PostgreSQL│   │ Redis (缓存) │
   │  数据库   │   │ 凭证/会话    │
   └─────────┘   └─────────────┘
                │
        ┌───────┴───────┐
        │  微信支付 API   │
        │  微信登录 API   │
        └───────────────┘
```

### 6.2 技术栈

| 层次 | 技术 | 说明 |
|------|------|------|
| 前端 - 小程序 | 微信原生 (WXML/WXSS/JS) | MVP 无框架，快速开发 |
| 前端 - 后台 | Vanilla JS + CSS | 轻量，无构建工具 |
| 后端框架 | FastAPI (Python 3.11) | 异步、自动文档 |
| 数据库 | PostgreSQL 15 | 主数据库 |
| 缓存 | Redis | 会话、二维码缓存 |
| 支付 | 微信支付 JSAPI v3 | 小程序支付 |
| 部署 | Docker + Nginx | 单机部署 |
| 服务器 | 腾讯云轻量 / 阿里云 ECS | 2C4G, ¥68-100/月 |

### 6.3 数据库核心表 (初版)

```
景区景区 (scenic_spots)
  ├── 票型 (ticket_types)
  ├── 订单 (orders)
  │     └── 订单明细 (order_items)
  ├── 核销记录 (verification_records)
  ├── 用户 (users) — 游客 + 员工
  ├── 员工 (staff)
  └── 操作日志 (audit_logs)
```

## 七、风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
